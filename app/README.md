# Pip's Puzzles: app

React Native + Expo (SDK 57) with Expo Router. See the main [README](../README.md) for setup.

```bash
npm install          # first time only
npx expo start       # scan the QR code with Expo Go

npm run typecheck    # TypeScript
npx expo lint        # ESLint
npm run test:logic   # jigsaw + maze rules (plain Node)
```
