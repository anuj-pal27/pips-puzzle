Waiting for the first plays

The game sends a short, anonymous note to this server when a child starts, finishes or leaves a puzzle (no names, no accounts: just a random id per phone). Notes are kept on the phone while it's offline and sent later. Open the game on a phone connected to this server and play a puzzle, and the numbers appear here.

Want to see the dashboard with numbers first? python manage.py demo_analytics adds made-up plays (and --clear removes them).
